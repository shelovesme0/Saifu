# Резервна копія Saifu

Функція поза лабораторними: експорт і імпорт усіх даних у JSON та автоматична копія в папку, яку обрав користувач. Працює без нових capabilities і без платного акаунта розробника: папку вибирає системний Document Picker (`.fileImporter`), доступ до неї зберігається як security-scoped bookmark, а на iOS це не потребує entitlements.

## Що потрапляє в копію

Усі гаманці в поточному порядку, кожен з витратами, поповненнями та останньою звіркою. Налаштування (домашня валюта, нагадування) лишаються в `UserDefaults` і в копію не входять.

## Формат файлу (версія 1)

```json
{
  "appVersion" : "1.0 (1)",
  "createdAt" : "2026-11-24T09:05:12.481Z",
  "formatVersion" : 1,
  "wallets" : [
    {
      "currency" : "jpy",
      "expenses" : [
        {
          "amount" : 580,
          "category" : "smallShop",
          "date" : "2026-11-24T08:41:03.112Z",
          "id" : "4F09E482-5CB8-42AC-A39F-E9AE47716F52",
          "note" : "7-Eleven"
        }
      ],
      "id" : "0C1D6F0E-2B8A-4C47-9B0E-7E2C1B1F9A10",
      "lastReconciliation" : {
        "actual" : 18500,
        "date" : "2026-11-24T08:50:00.000Z",
        "expected" : 18470
      },
      "name" : "Японія",
      "topUps" : [
        {
          "amount" : 20000,
          "date" : "2026-11-24T08:00:00.000Z",
          "id" : "A3B1C2D4-1111-4222-8333-944455556666",
          "source" : "atm"
        }
      ]
    }
  ]
}
```

- **Суми** — `Int` у найменших одиницях валюти гаманця (єни, копійки, центи), як і в моделях.
- **Enum-и** — `rawValue`: `currency` (`jpy`, `uah`, `eur`, `usd`), `category` (`food`, `groceries`, `smallShop`, `transport`, `household`, `leisure`, `untracked`), `source` (`atm`, `correction`).
- **Дати** — ISO 8601 в UTC з мілісекундами. Дата округлюється до мілісекунди і при записі, і при читанні, тому повторний експорт відновлених даних дає той самий файл.
- **Порядок гаманців** — порядок масиву `wallets`. Записи всередині гаманця впорядковані за датою.
- `note`, `receiptID`, `lastReconciliation` необов'язкові.

Формат описують окремі Codable-DTO (`Saifu/Backup/BackupDTO.swift`), а не доменні моделі. Модель можна змінювати, не ламаючи старі файли: несумісна зміна формату означає нове значення `formatVersion` і окреме читання старої версії.

## Імпорт і перевірка

1. Спершу читається лише `formatVersion`. Якщо це не JSON або поля немає, з'являється повідомлення «Файл пошкоджений або не є резервною копією Saifu». Невідома версія дає «Копію створено новішою версією застосунку (формат N)».
2. Потім файл розбирається повністю й перевіряється: відомі валюта, категорія й джерело поповнення, суми > 0, фактична сума звірки ≥ 0, коректні дати, унікальні id гаманців і записів.
3. Лише після успішної перевірки з'являється підтвердження «Поточні дані буде замінено. Перед цим буде збережено їхню копію».
4. Після «Замінити» поточні дані зберігаються у `Saifu-before-import-YYYY-MM-DD-HHmm.json`: у папку автокопії, якщо вона обрана й доступна, інакше в Documents застосунку («Файли → На iPhone → Saifu»). Якщо цю копію записати не вдалося, імпорт скасовується.
5. `WalletRepository.replaceAll(with:)` замінює всі дані однією транзакцією SwiftData. Якщо запис не вдався, контекст відкочується, і в пам'яті та на диску лишаються попередні дані.
6. Екрани оновлюються: репозиторій `@Observable`, тому головна, аналітика й список гаманців перераховуються самі. Відкриті екрани й sheet закриваються (`AppRouter.resetNavigation()`), а форми додавання витрат створюються наново, бо тримали старі екземпляри `CashWallet`.

На кроках 1–4 поточні дані не змінюються.

## Автоматична копія

- **Увімкнення.** Налаштування → «Резервна копія» → «Автоматична резервна копія». Тумблер відкриває вибір папки (можна обрати й папку в iCloud Drive). Після вибору одразу створюється перша копія: так перевіряється, що в папку можна писати. Якщо закрити пікер без вибору, тумблер повертається у вимкнений стан.
- **Коли пишеться.** Коли застосунок переходить у фон (`scenePhase == .background`) і виконано дві умови:
  - від останньої автокопії минула щонайменше година;
  - дані змінилися. Застосунок порівнює SHA-256 від JSON гаманців (без дати створення) з відбитком останньої автокопії, тому лічильник змін у репозиторії не потрібен.

  Запис обгорнутий у фонове завдання (`beginBackgroundTask`), щоб iOS не призупинила застосунок посеред запису.
- **Імена й ротація.** `Saifu-backup-YYYY-MM-DD-HHmm.json`. Ім'я сортується так само, як час, тому в папці лишаються 7 найновіших автокопій, а старіші видаляються. Файли `Saifu-before-import-…` і файли інших застосунків не чіпаються.
- **Втрата доступу.** Якщо папку видалили, перейменували так, що bookmark не відновлюється, або доступ відкликано, у секції з'являється попередження і кнопка «Вибрати папку знову». Якщо папку перемістили, а bookmark ще відновлюється (`isStale`), він тихо оновлюється.
- **Вимкнення** забуває папку. Файли в ній лишаються.

## Ручні дії

- **«Експортувати зараз»** відкриває `.fileExporter` з ім'ям `Saifu-backup-YYYY-MM-DD-HHmm`. Файл можна зберегти будь-куди у «Файлах».
- **«Імпортувати»** відкриває `.fileImporter` для JSON, далі працює як описано в розділі «Імпорт і перевірка».
- Під секцією показується дата останньої копії (автоматичної або експортованої).

## Компоненти

| Тип | Файл | Роль |
|---|---|---|
| `BackupFileDTO` та інші DTO | `Saifu/Backup/BackupDTO.swift` | Формат файлу, мапінг домен ↔ DTO з перевіркою |
| `BackupService`, `JSONBackupService`, `BackupDate` | `Saifu/Backup/BackupService.swift` | Експорт, відбиток, перевірка, відновлення через `WalletRepository` |
| `BackupFolderAccess`, `BookmarkBackupFolder`, `BackupFileName` | `Saifu/Backup/BackupFolder.swift` | Bookmark у `UserDefaults`, запис і ротація файлів у папці |
| `BackupDocument` | `Saifu/Backup/BackupDocument.swift` | `FileDocument` для `.fileExporter` |
| `BackupError` | `Saifu/Backup/BackupError.swift` | Помилки й тексти для користувача |
| `BackupViewModel` | `Saifu/ViewModels/BackupViewModel.swift` | Стан секції, правила автокопії, імпорт з копією перед заміною |

`SettingsView` лише показує стан і викликає `BackupViewModel`. Конкретні `JSONBackupService` і `BookmarkBackupFolder` створюються в композиційному корені (`SaifuApp` / `ScreenFactory`).

Щоб Documents застосунку було видно у «Файлах», додано ключі Info.plist: `LSSupportsOpeningDocumentsInPlace` (налаштування збірки) і `UIFileSharingEnabled` (`Saifu-Info.plist`, який Xcode зливає зі згенерованим Info.plist). Це ключі Info.plist, а не capabilities.

## Покрокова перевірка (симулятор)

1. Створити гаманець, додати витрати й поповнення, звірити.
2. **Експорт:** «Експортувати зараз» → «На iPhone» → зберегти. Під секцією з'являються «Копію експортовано» і дата.
3. **Імпорт:** видалити гаманець або додати витрату → «Імпортувати» → вибрати файл → «Замінити». Дані й порядок гаманців повертаються на всіх вкладках, повідомлення каже, куди збережено попередні дані (`Saifu-before-import-…json`).
4. **Пошкоджений файл:** у «Файлах» обрізати JSON або змінити `"formatVersion" : 1` на `99` (чи просто імпортувати будь-який інший JSON). З'являється зрозуміла помилка, підтвердження не показується, дані без змін.
5. **Автокопія:** увімкнути тумблер → вибрати папку → з'являється перша копія. Змінити дані → Home → нового файлу немає, бо минуло менше години.
   Щоб не чекати годину: `xcrun simctl spawn booted defaults delete com.vitaliilazariev.Saifu lastAutoBackupDate`, потім знову вийти у фон. Без змін у даних новий файл не з'являється.
6. **Ротація:** покласти в папку 8+ файлів `Saifu-backup-2020-01-0X-0000.json`, викликати автокопію → лишається 7 найновіших.
7. **Втрата доступу:** видалити папку у «Файлах» → змінити дані, скинути `lastAutoBackupDate`, вийти у фон і повернутися. Секція показує попередження й «Вибрати папку знову».
